# UEMP Academic Administration

This glossary defines the account and academic-record language used across the university portal.

## Language

**User account**:
A person’s sign-in identity, role, and access status in UEMP.
_Avoid_: User profile, login

**Academic profile**:
The institutional student or lecturer record attached to a user account. A student profile carries programme, level, and matriculation identity; a lecturer profile carries department assignment.
_Avoid_: Account details

**Account status**:
The administrator-controlled state that determines whether a user account may authenticate and use protected services.
_Avoid_: Profile status

**Session revocation**:
The invalidation of a user account’s active authenticated sessions without deleting the account or its academic profile.
_Avoid_: Account reset, logout
